## 4. Errors & Bugs Fixed

1. **`telemetry/collector.py` — `fix.speed_mps` AttributeError (latent, production-affecting).**
   - **Symptom:** `collect()` would raise `AttributeError: 'GPSFix' object has no attribute 'speed_mps'` whenever a real GPS fix was present. Unhit until now because tests never ran `collect()` with a populated GPS.
   - **Root cause:** typo — `GPSFix` field is `speed_ms`, collector read `speed_mps`.
   - **Fix:** `snap.speed_mps = fix.speed_ms`. Surfaced by the new telemetry-snapshot test.

2. **`core/main.py::_gps_provider()` — wrong GPSManager attributes (latent).**
   - **Symptom:** referenced `self._gps_manager.has_fix` / `.latitude` / `.longitude`, none of which exist on `GPSManager`; would AttributeError in teach mode with GPS present. Unhit because gps_manager is `None` in sim.
   - **Root cause:** `GPSManager` exposes `.position` (tuple) and `.fix`, not those attributes.
   - **Fix:** rewrote to use `.position` + `.fix.altitude_m`, and added `alt` to the returned dict (also satisfies Task 4).

3. **`vision/node.py` — `is_calibrated()`/`has_bird_eye()` called as methods.**
   - **Symptom:** loopback test crashed with `'bool' object is not callable`.
   - **Root cause:** they are `@property` on `CameraManager`.
   - **Fix:** call without parens; made `RemoteCameraManager`'s equivalents `@property` for parity. Also made `VisionNode.stop()` idempotent (it's invoked from both `start()`'s finally and the caller).

4. **`scripts/install.sh` — `apply_compute` array/scalar clobber.**
   - **Symptom:** the "no compute flags" detection would misfire because `export_compute_env` overwrote the `CO_ROLES` bash array with a scalar before its length was checked.
   - **Fix:** folded env-export into `apply_compute`, used distinct CSV env var names, checked the arrays before mutating. Functionally verified (valid split writes correctly; unsafe control-delegation rejected with nonzero exit).
